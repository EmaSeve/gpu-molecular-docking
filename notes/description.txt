ACA Project



Obiettivo del progetto è quello di scrivere un programma prima in C++ e poi ottimizzarlo in CUDA, che svolga le seguenti operazioni:

    INPUT: un file CSV in cui ci sono le posizioni (x,y,z) di ogni atomo della proteina target e i valori associati per quel tipo di canale,
        (i canali totali sono 8), 
        un file CSV in cui ci sono le posizioni (x,y,z) degli atomi della molecola che si vorrà legare alla proteina,
        con il valore specifico 

    Execution:

    1. scrivere la funzione che discretizzi le posizioni :
        creare una maschera 3D (Cubo) che mappi ogni posizione degli atomi in una cella del Cubo
    2. creare quindi la struttura dati che salvi per ogni cella del cubo i valori associati agli
        8 canali disponibili
    3. data la struttura discretizzata della proteina, per ogni atomo della molecola che si deve legare:
        - calcolo la posizione dell'atomo nella cella del cubo, cioè trovo l'atomo della proteina
          che si trova nella stessa posizione relativa.
        - calcolata la cella, faccio il prodotto tra i valori delle due celle:
            type 1: 
                per ogni canale (8 totali) calcolo il valore, cioè avrò 8 valori per ogni atomo della molecola,
                e questi verranno salvai in 8 array di lunghezza n 
            type 2:
                in questo caso si avrà un solo array di output, perchè ogni atomo della molecola che si lega sarà
                valutato solo con uno degli 8 canali, in base a quanto specificato da una condizione 
                -> (If type == 1): then use the first channel's value to perform the product
                -> (If type == 4): then use the fourth channel's value to perform the product
